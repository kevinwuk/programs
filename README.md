Welcome this is MY Mega Website Portal, which is an epic single file website containing fourteen totally different pages in one place because I haven't figured out how server routing works yet! You can check out the live demo link to see the whole thing in action. Visually, it looks super clean with a dark mode, custom cards, photo grids, and a retro scrolling marquee message at the top just like websites from 1999n
Getting this to run on your computer is super easy and doesn't need any complicated stuff like npm install or node modules because it's just pure front-end code. All you have to do is download or clone the project files and double-click the index.html file to open it right up in your web browser. No special environment variables or secret API keys are needed at all, so you can go from wanting to see it to actually looking at it in like five seconds.
Even though I am a beginner, its filled with features like fourteen functional pages covering everything from my coding blog and PC setup to my pet fish and my serious food tier list rankings. It uses advanced CSS variables, Flexbox, and CSS Grid to look amazing, and it even switches colors automatically depending on whether your computer is in light mode or dark mode.
Instead of using a complicated backend server router to switch between pages, I use HTML anchor tags combined with CSS so everything stays in one file that loads instantly without crashing.
