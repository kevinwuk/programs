Study Notes & Articles

Understanding Document Semantics

Posted: October 2026

When starting out, it is easy to wrap every text block inside non-semantic division containers. Switching to semantic elements like header, main, section, and article makes the HTML structure instantly readable and improves browser accessibility.

Why Master HTML Before CSS?

Posted: October 2026

Attempting to fix broken layout issues with complex CSS rules is often a symptom of poorly structured HTML. Spending extra time organizing headings, paragraphs, lists, and forms properly eliminates layout friction later on.

Git Version Control Essentials

Posted: September 2026

Version control allows tracking progress incrementally. Committing code changes frequently provides a safety net when experimenting with new layouts or rewriting existing HTML blocks.

HTML Tag Quick Reference Table

This table summarizes common HTML elements and their standard primary usage:

Element Tag Type Primary Function Self-Closing?
<h1> - <h6> Block Defines heading levels 1 through 6 No
<p> Block Defines standard body paragraph text No
<a> Inline Creates hyperlinks to external pages or internal target IDs No
<img> Inline-Block Embeds an image using src and alt attributes Yes
<ul> / <ol> Block Defines unordered (bulleted) or ordered (numbered) lists No
<table> Block Renders structured tabular data in rows and columns No

Developer Utilities Cheatsheet

Key command line commands used for repository management:

  • git init — Initializes a brand new local repository in the current folder.
  • git status — Checks the state of working directory files and staged commits.
  • git add . — Stages all modified files in the working directory for commit.
  • git commit -m "Message" — Saves staged changes into repository history with a descriptive note.
  • git push origin main — Uploads local repository commits to the remote GitHub branch.
